Quick questions

What if a spot is closed when I get there?

I check current hours and note which days each stop is open. If a place is unreliable on a given day, I say so plainly and hand you a backup.

Can I ask for dietary restrictions?

Yes. Vegan, halal, allergies, no pork, no shellfish, whatever it is. Put it in the brief and I filter for it. If a place can’t do it, it doesn’t go in the report.

How do I receive the report?

As a link to a web page like the samples on this page, and a PDF if you’d rather keep it offline. Nothing to install.

Is this for Manila only?

Manila is home, so it’s the fastest. Anywhere else, send the area and I’ll tell you honestly whether I can check it properly before you pay.
